## **FlightDeck** - An Airport Management System

**FlightDeck** is a system for tracking and coordinating airport operations. It monitors incoming and outgoing flights in real time, displaying their current status (scheduled, boarding, departed, landed, delayed, etc.) alongside other operational details.

### Key Features

-  **Flight Tracking** - Monitor incoming and outgoing flights with  status updates
-  **Runway Management** - Assign and manage runway usage for departures and arrivals
-  **Bay Allocation** - Allocate parking bays to aircraft and track occupancy
-  **Centralized Information** -g Get a unified view of airport activity for easier coordination
