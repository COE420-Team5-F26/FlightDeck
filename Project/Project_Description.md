# Project Description

FlightDeck is a system for tracking and coordinating airport operations. It monitors incoming and outgoing flights in real time, displaying their current status (scheduled, boarding, departed, landed, delayed, etc.) alongside other operational details.

## Problem / Need
Coordinating flight status, runway usage, and bay assignments manually is error-prone and hard to track in real time. FlightDeck addresses this by giving airport staff a single system to monitor and manage these operations as they happen.

## Intended Users
Airport operations staff, ground control personnel, and airline coordinators who need an up-to-date view of flight and airport activity.

## Key Features
- **Flight Tracking** - Monitor incoming and outgoing flights with status updates
- **Runway Management** - Assign and manage runway usage for departures and arrivals
- **Bay Allocation** - Allocate parking bays to aircraft and track occupancy
- **Centralized Information** - Get a unified view of airport activity for easier coordination

## Key Functionalities
- Display real-time status of all tracked flights
- Assign and update runway usage per flight
- Assign, occupy, and free up parking bays
- Present a consolidated dashboard of current airport operations
